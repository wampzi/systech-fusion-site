# Systech Fusion — Marketing Website

Static marketing site for Systech Fusion (IT consultancy).
Pure HTML / CSS / vanilla JS — no build step required.

## Local preview
Just open `index.html` in a browser, or serve the folder with any static server:

```powershell
# Option A — Python
python -m http.server 8080

# Option B — Node (npx)
npx serve .
```

Then visit <http://localhost:8080>.

## Project structure
```
index.html          Home
services.html       Services + plans
about.html          About / values
careers.html        Open roles
contact.html        Contact / quote form (mailto handoff)
styles.css          Design system
script.js           Header, nav, reveal, counters, contact form
assets/images/      Local hero / section photos
```

## Deployment
Hosted on **GitHub Pages**. Pushes to `main` are served from the repository root.
